# VR Recovery Tool

Windows 10/11 x64 data-preparation tool. It formats recovery requests but does not execute recovery operations.

## Download

Download the versioned `.exe` from [the latest release](https://github.com/khaleesilin-ux/vr-recovery-tool/releases/latest). No installation or ZIP extraction is required. The executable is not code-signed; follow your organization's security approval process.

## Updates

Starting with v1.3.14, click the application's Version Update button. Confirm the update to download, verify and restart. Export any results you need before updating. No GitHub account is required. Business data and OCR are processed locally; only an explicit update check/download contacts GitHub.

Each release contains `vX.Y.Z.exe` and a matching `update.json` with the version, filename, SHA-256 and release notes. Both must be uploaded before publishing. This repository distributes release artifacts, not user data.
